# OptiPay Website Screenshot Directory

Drop your software screenshots directly into this folder (`optipay-brand-website/public/features/`).

---

### Required Screenshot Naming Conventions

| Filename | Which Screen to Capture | Suggested Resolution |
| :--- | :--- | :--- |
| **`pos-billing.png`** (or `.jpg`) | The main POS counter screen showing cart with frames, lenses, and total billing. | 1920x1080 (or 16:9) |
| **`clinical-rx.png`** (or `.jpg`) | The Clinical Prescription entry modal/page showing OD/OS Sphere, Cyl, Axis, Add & PD. | 1920x1080 (or 16:9) |
| **`split-gst-invoice.png`** (or `.jpg`) | A completed GST invoice or 80mm thermal receipt preview showing split HSN 9001 & 9003 taxes. | 1080x1080 or A4/Receipt crop |
| **`lab-job-slip.png`** (or `.jpg`) | The edging lab fitting slip / workshop order ticket with advance deposit token. | 1080x1080 or 16:9 |
| **`frame-inventory.png`** (or `.jpg`) | The collections/inventory screen showing frame brands, barcodes, and stock quantities. | 1920x1080 (or 16:9) |
| **`store-analytics.png`** (or `.jpg`) | The insights/dashboard screen showing daily revenue, top brands, and order trends. | 1920x1080 (or 16:9) |

---

### Tips for Best Visual Quality:
1. **Resolution:** High-DPI / 1080p or 1440p (crisp text, no blurry scaling).
2. **Data:** Use clean sample customer names (e.g., "Ramesh Patel", "Vision Care") and real optical powers.
3. **Format:** PNG is preferred for crisp text and UI lines; high-quality JPG is also accepted.
